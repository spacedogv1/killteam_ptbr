# Kill Team Ops

Aplicativo responsivo, em português, para consulta das missões e Tac Ops de Kill Team Approved Ops 2025.

## Rodar localmente

Requer Node.js 22 ou superior e pnpm.

```powershell
pnpm install
pnpm run dev
```

Depois, abra `http://localhost:3000` no navegador.

## Inclui

- 9 Missões da Partida (Operações Críticas)
- 12 Tac Ops, filtráveis por arquétipo
- Tradução PT-BR com erratas oficiais até abril de 2026
- PWA: depois do primeiro carregamento completo, fica disponível sem conexão
